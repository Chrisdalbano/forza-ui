# Changelog

## 0.3.0 / September 17, 2026

First standalone open-source release.

- Separate component package, source-copy CLI, and VitePress site.
- Searchable SPA playground and individual component documentation.
- Generated API metadata, AI reference files, and agent instructions.
- Forward Fold identity, SVG assets, social artwork, and favicon set.
- New landing with readable supporting text and themed scrollbars.
- Scoped Ink and Paper themes, controlled state, and reduced motion.

## 0.2.0 / Preview

Expanded the BuildValue design exploration to 25 components, including stepper, accordion, carousel, drawer, dropdown, select, checkbox, slider, tooltip, popover, alert, table, and pagination.

## 0.1.0 / Preview

Established Forza's tokens, controls, Lucide icon wrapper, and list motion. These previews were local explorations, not npm releases.
